# ⛳ Global Golf

A geography game where you navigate the world capital by capital — or challenge the 50 US state capitals — in as few strokes as possible.

## Game Modes

- **Daily** — Same world capitals puzzle for everyone, resets at midnight
- **Random** — Fresh random world capitals challenge
- **US Daily / US Random** — Same game but with US state capitals only
- **1v1** — Pass-and-play against a friend on the same device
- **vs CPU** — Challenge the computer on Easy, Medium, or Hard
- **Battle Royale** — 2–4 players, pass-and-play

## How to Play

1. You start at a random world (or US state) capital
2. A target capital is shown — navigate to it in as few strokes as possible
3. Each round, pick a club (each has an ideal distance range) and type your next destination
4. Using the wrong club for the distance earns a penalty stroke
5. Score is measured relative to par — aim for birdie or better!

## Tech

Pure HTML, CSS, and vanilla JavaScript. No build step required.  
Globe rendered with [globe.gl](https://globe.gl/).

## Local Development

Open `index.html` directly in a browser — no server needed.
